- MODEL_PATH = models/best.pt

Weight:
- models/best.pt co trong repo.
- Comment trong utils/config.py ghi model YOLO da fine-tune tren Google Colab.
- Khong tim thay script train YOLO trong repo hien tai.

Pipeline:
1. ObjectDetector.__init__ load YOLO(model_path).
2. ObjectDetector.detect(frame) goi model.predict(frame, conf=0.5, imgsz=640, verbose=False).
3. Lap qua result.boxes.
4. Lay class_id tu box.cls[0].
5. Lay confidence tu box.conf[0].
6. Lay class_name tu self.model.names[class_id].
7. Neu class_name khong nam trong COCO_CLASSES thi bo qua.
8. Lay bbox xyxy va doi sang int.
9. Tra list dict gom class_name, confidence, box.

IOU:
- Khong tim thay cau hinh IOU trong source code hien tai.
- Source khong truyen tham so iou vao model.predict.

Preprocessing:
- Khong tu cai dat trong project.
- Anh/frame OpenCV duoc truyen truc tiep vao Ultralytics.

Postprocessing:
- Co loc class theo COCO_CLASSES.
- Co parse bbox/confidence.
- Khong thay custom NMS ngoai Ultralytics.

CHUONG 8. PHAN TICH k-NN
============================================================

File chinh: ml/knn.py
Vai tro: goi y cac tu lien quan trong vocabulary.

Input:
- word: str
- n: int = 3
- Du lieu nen: dataset/vocabulary.csv

Feature:
- word_length: do dai tu tieng Anh.
- level_encoded: Easy=0, Medium=1, Hard=2.
- one-hot category.

Chuan hoa:
- StandardScaler.

Trong so feature:
- CATEGORY_WEIGHT = 5.0
- LEVEL_WEIGHT = 2.0
- WORD_LENGTH_WEIGHT = 0.5

Model:
- sklearn.neighbors.NearestNeighbors
- n_neighbors = len(dataframe)
- metric = "euclidean"
- Luu tai models/knn.pkl

Function:
- read_vocabulary(): doc va chuan hoa CSV.
- build_features(dataframe): tao feature.
- apply_feature_weights(features, feature_columns): nhan trong so.
- get_dataset_modified_time(): lay mtime vocabulary.csv.
- train_knn_model(): train NearestNeighbors va dump joblib.
- load_knn_model(): load model hoac train lai neu thieu/het han/sklearn version khac.
- get_related_words(word, n): tra danh sach tu gan nhat.

Output get_related_words:
- english
- vietnamese
- category
- level
- distance

Flow:
word -> normalize lower/strip -> load_knn_model -> tim index trong vocabulary
-> lay feature cua tu -> scaler.transform -> apply weights -> kneighbors
-> bo qua chinh tu dau vao -> tra n tu lien quan.

Vai tro trong he thong:
- Sau khi YOLO phat hien vat the, UI lay object co confidence cao nhat va goi get_related_words.
- Ket qua hien trong muc "Tu goi y" tren CameraPage.
